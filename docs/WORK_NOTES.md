# 작업 메모 — 위상수학 교실 (topology_ai_lab)

- 독자 진단: 주 독자를 정하지 않아 **혼합형**으로 가정 (수식 막힘 처방 먼저, 해석 연습은 뒤에).
- 주 독자 한 줄: 위상수학을 처음 보는 중학생, 행렬·벡터도 아직 배우는 중인 학생.
- 원자료: 사용자가 준 인포그래픽 20장 (`img/source/src01~20.webp`). 출처 미상 — 꾸러미에서 "확인 필요".
- 원자료와 다른 값은 저자 확인 전 기본값대로 "원자료의 A를 이 페이지에서는 B로 바꿉니다"로 표기.
- 분야: 수학(위상수학) 주 분야, 인공지능(이미지 처리·데이터 구조) 보조. 비유 앵커는 D(일상).

## 검산한 숫자
- 점 3개 집합의 위상 개수 29, 점 4개 355 (전수 조사 스크립트).
- 모듈러 군 기본 영역 넓이(쌍곡 넓이) = π/3 − 1/T (높이 T에서 자를 때), T→∞이면 π/3 ≈ 1.047.
- 카포비치 반례: p=(1, 2ⁿ)는 n이 음수로 갈수록 (1,0)에 붙고, 도장 gⁿ을 찍은 (2ⁿ, 1)은 (0,1)에 붙는다 → 아무리 작은 동그라미를 잡아도 겹치게 하는 도장이 무한히 많다.
- 점 4개 이산 위상의 열린 집합 2⁴ = 16개.
