# 위상수학 교실 — 고무찰흙 세상의 수학

중학생도 따라올 수 있게 만든 위상수학 연구실 해설 시리즈예요. 인포그래픽 20장에 담긴 개념(이산 위상, 연결, 콤팩트, 디지털 위상, 알렉산드로프 공간, 군의 작용, 디리클레 영역과 격자, 덮개 공간과 갈루아 대응, 함자와 수반, 울트라필터와 스톤-체흐, 아주 끊긴 공간과 프로유한 공간)을 15장으로 나누고, 장마다 다른 수업 형식(1:1 토론, 조별 과제, 계산배틀, 발표수업 등)으로 풀었어요.

- 선생님: 박사 · 조교: 초파리 연구원, 주판봇 · 수강생: 인턴 시아, 인턴 모아, 조수 하루, 미공개 X1·X2·X3
- 1조 「도넛조」 시아·하루·X1 / 2조 「머그조」 모아·X2·X3

**바로 보기:** https://adminmrobo.github.io/topology_ai_lab/ (GitHub Pages를 켜면 열려요)

## 구성

- `index.html`, `NN_*.html`, `practice/index.html` — 페이지 (외부 라이브러리 없음, 글꼴만 외부 요청, 브라우저 저장소 사용 안 함)
- `assets/` — 공용 스타일(`lab.css`), 캐릭터·용어·퀴즈·대결(`lab.js`), 그림 실험(`widgets.js`), 실전 연습장(`practice.js`), 캐릭터 그림(`sprites.js`), 지식 색인·꾸러미(`js/kgx.js`)
- `content/` — 장별 내용 데이터, `tools/build.py` — 조립 스크립트 (`python3 tools/build.py --sprites <캐릭터 팩 폴더>`)
- `img/source/` — 원자료 인포그래픽 20장(사용자 제공), `img/og/` — 공유 미리보기
- `docs/IMG_specs.md` — 표지 그림 제작 명세서(16비트 RPG 픽셀아트 지시문), `docs/WORK_NOTES.md` — 사실 카드·원자료 바로잡기·검산 기록
- `cover_manifest.json` — 표지·온톨로지 현황판 연결 파일
